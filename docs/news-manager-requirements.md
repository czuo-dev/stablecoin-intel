# 新闻管理器需求文档

## 功能
1. 保存新闻
   - 标题、来源、分类、链接
   - 自动添加时间戳
   - 保存到 JSON 文件

2. 读取新闻
   - 从 JSON 文件加载
   - 如果文件不存在，创建空数据库

3. 搜索新闻
   - 按关键词搜索标题
   - 按分类筛选

4. 显示新闻
   - 列表形式显示
   - 显示前10条

5. 统计
   - 按分类统计数量
   - 按来源统计数量

## 数据结构
新闻对象:
{
  "id": 1,
  "title": "标题",
  "source": "来源",
  "category": "分类",
  "url": "链接",
  "added_at": "时间"
}

## 文件
- data/news_database.json（主数据库）
- data/news_backup.json（备份）
