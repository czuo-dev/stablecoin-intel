# 稳定币行业情报 Agent

> 自动追踪稳定币行业的政策、大公司动态和融资新闻

## 🎯 项目目标

帮助创业者和投资者快速了解稳定币行业动态，包括：
- 全球监管政策变化
- 大公司稳定币布局
- 融资和投资事件

stablecoin-intel/
